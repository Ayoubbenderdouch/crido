## Shared Style Guide (paste this in every prompt as a prefix or include the key tokens)

**Style:** soft 3D-rendered illustration, modern, friendly, lit with warm soft light, slight ambient occlusion, very slight rim light in bright teal. Matte surfaces, no harsh reflections. Inspired by Tamara/Klarna/Stripe illustration sets. Slightly stylized characters, not photo-real — clean, approachable, premium fintech feel.

**Color palette (strict):** Primary teal `#0F6E56`, deep teal `#04342C`, bright teal `#1D9E75`, surface teal `#E1F5EE`, cream `#F7F6F1`, cream deep `#EEEDE3`, amber accent `#EF9F27` (sparingly), ink `#1A1A18`. Avoid red, blue, purple, pink, neon green, saturated yellow. No off-palette colors.

**Composition:** clean background (cream or surface teal unless prompt specifies otherwise), generous whitespace, subject centered or off-center per spec, soft floating shadow underneath subject, no heavy gradients except where explicitly noted.

**Cultural notes:** modern Algerian/Maghrebi context — young adults in their 20s–30s, dignified, contemporary clothes (NOT traditional dress unless prompt explicitly says so). Skin tone: warm olive/light brown, natural. Avoid clichés and tourism imagery.

**Forbidden:** AI-typical disfigurements, ugly hands/eyes, extra fingers, kitsch, religious symbols (no mosque/crescent/cross unless explicit), competitor logos, English text in images unless specified, any text containing the word "interest" or "intérêt" or "فائدة".

**Render hint:** Octane/Blender style soft 3D, 4k quality, depth of field disabled, no chromatic aberration, no film grain.

## Tips for Generation

- **Generate P01 (hero) first.** Its style, lighting, and character render quality will set the tone for the entire set. Use it as a reference for color, lighting direction, and material finish when prompting the rest.
- **Paste the Shared Style Guide** (above) as a prefix before each prompt the first few times to anchor the model on the palette and style. After several generations in the same chat, the model usually maintains style consistency.
- **Save each output as PNG with transparency where possible** (especially P10, P11, P15) so you can layer them over different section backgrounds in code.
- **If GPT-4o adds unwanted text or readable English/garbled Arabic** inside the image, regenerate the prompt with the tag `no text, no signage, no readable characters anywhere in the image` appended at the end.
- **For consistent character renders across the set** (P01, P12), explicitly mention "warm olive skin tone, modern short haircut, dignified, 28–30 years old, contemporary Algerian/Maghrebi" in every character prompt — these tokens improve consistency.
- **If the model struggles with Arabic text inside UI screens** (P02–P05), generate the screen with placeholder Latin text first, then composite the real Arabic text in Figma/Photoshop afterward — GPT-4o's Arabic rendering is unreliable for small UI text.
- **For 3D icon sets** (P10, P11), prompt each icon individually for best quality, then composite the grid in code/Figma rather than asking GPT-4o to render a grid in one shot (single-shot grids often have inconsistent lighting between items).
- **File names matter for the dev integration.** Save each file with the exact suggested filename so the landing code can reference them without modification.
- **Avoid amber overuse.** Amber `#EF9F27` should appear in only a handful of images (P09 coin stack, P13 sunset glow, P15 coin stack). Overusing amber breaks the teal-dominant brand feel.
- **Resolution upscaling:** if GPT-4o outputs at lower resolution, upscale via a quality upscaler (e.g., Topaz Gigapixel or an AI upscaler) — do NOT prompt the model to "increase resolution" inline, which often degrades quality.
- **Iterate per image.** Plan 2–4 generations per prompt to pick the best result. Discard any with anatomical issues (hands, eyes), broken text, or off-palette colors.
